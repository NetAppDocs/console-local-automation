= Run a MetricsQL query for systems in an organization in NetApp Console local deployment
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/organizations/{organization_id}/metricsql`#



Run a raw MetricsQL query against time series data for systems in an organization.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|organization_id
|string
|path
|True
a|Identifier for an organization.


|===

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|query
|string
|True
a|MetricsQL query.


|timeRange
|link:#asset_1_0_time_range[asset_1.0_time_range]
|False
a|Time range for a query window. If omitted from the request body,
an instant query is performed at the evaluation time. If provided in the request body, a range query is performed. Values can be absolute or relative to the
evaluation time.


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "query": "sum(iops_total) by (cluster)",
  "timeRange": {
    "end": "NOW",
    "start": "PT30M",
    "step": "PT1M"
  }
}
====

[#asset_1_0_time_range]
[.api-collapsible-fifth-title]
asset_1.0_time_range

Time range for a query window. If omitted from the request body,
an instant query is performed at the evaluation time. If provided in the request body, a range query is performed. Values can be absolute or relative to the
evaluation time.


[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|end
|string
|False
a|End of the query window. The value can be:

* RFC 3339 timestamp (e.g. "2026-01-23T10:00:00Z"),
* "NOW",
* ISO 8601 duration interpreted as NOW minus the duration
(e.g. "PT15M" = NOW-15 minutes).
If omitted, defaults to "NOW".


|start
|string
|True
a|Start of the query window. The value can be:

* RFC 3339 timestamp (e.g. "2026-01-23T10:00:00Z"),
* "NOW",
* ISO 8601 duration interpreted as NOW minus the duration
(e.g. "PT15M" = NOW-15 minutes).


|step
|string
|False
a|ISO 8601 duration step between data points for range queries
(e.g. "PT60S"). Ignored for instant queries.


|===

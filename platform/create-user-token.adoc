= Create a user token for the NetApp Console (local deployment) 
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
You need a user access token to authenticate REST API calls on behalf of a local user in the NetApp Console (local deployment). The token is obtained directly from the local identity provider on the NetApp Console (local deployment) instance.

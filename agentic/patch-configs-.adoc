= Apply an Agentic Platform configuration in NetApp Console local deployment
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/configs/{config_id}`#



Triggers the Kubernetes (K8s) resource creation and applies the specified Agentic platform configuration. The PATCH endpoint orchestrates the full apply pipeline. A failed connection test sets the state to unsuccessful and does not apply K8s resources.
The AgentGateway automatically hot reloads the updated configuration.

Provider-specific credentials can be updated using the corresponding provider object. Changing the provider in a PATCH request automatically removes the previous provider's Kubernetes (K8s) resources.

|False
a|OpenAI provider-specific configuration


|port
|integer
|False
a|Gateway port


|proxyConfigured
|string
|False
a|Indicates whether a proxy is configured for this LLM backend. This field reflects whether a cluster-level proxy is active. It is set automatically and should not be set by callers.
Defined values are:

* "true"  - A proxy is configured and active for outbound LLM traffic
* "false" - No proxy is configured; LLM traffic is routed directly


|requestsPerMinute
|integer
|False
a|The rate limit - maximum requests per minute (0 = unlimited).


|sslVerify
|boolean
|False
a|Indicates whether to verify SSL certificates.


|stateDesired
|string
|False
a|Desired state for the configuration lifecycle transition.
Use this field to request a state change for the configuration.
Defined values are:

* "DRAFT" - Move configuration to draft mode
* "TESTING" - Tests the LLM provider connection only. Does not create or modify AgentGateway resources. The llmHealthState is updated to reflect the test result.
* "SUCCESSFUL" - Mark configuration as having been successfully applied
* "UNSUCCESSFUL" - Mark configuration as having failed

NOTE: Only TESTING has a distinct behavior. DRAFT, SUCCESSFUL, UNSUCCESSFUL in stateDesired have no special effect -- the full apply pipeline runs.


|tokensPerMinute
|integer
|False
a|The rate limit - maximum tokens per minute (0 = unlimited).


|type
|string
|False
a|Media type of the resource.
Defined values are:

* "application/vnd.netapp.bxp.config"


|version
|string
|False
a|Version of the configuration format.
Defined values are:

* "1.0"

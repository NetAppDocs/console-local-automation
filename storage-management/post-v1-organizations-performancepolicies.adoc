= Create a new performance policy in NetApp Console local deployment
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/v1/organizations/{organizationId}/performancepolicies`#



Creates a new performance policy within the specified organization.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|organizationId
|string
|path
|True
a|Unique identifier of the organization.


|===

== Request Body

Expected to contain necessary parameters for creating a new performance policy.
                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|adaptive
|link:#adaptive_perf_policy_1_0[adaptive_perf_policy_1.0]
|True
a|Adaptive performance policy details.


|description
|string
|False
a|Description of the performance policy.


|name
|string
|True
a|Name of the performance policy.


|tags
|array[link:#tags[tags]]
|False
a|JSON array of tags (name/value pairs) associated with the performance policy. Can be used to add any additional data related to the performance policy.


|type
|string
|True
a|Media type of the resource.
Defined values are:

* "application/vnd.netapp.bxp.performancepolicy"


|version
|string
|True
a|Version of the resource schema.
Defined values are:

* "1.0"


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "adaptive": {
    "absoluteMinIopsPerTb": 1500,
    "expectedIopsPerTb": 2000,
    "expectedLatency": 200,
    "peakIopsPerTb": 3000
  },
  "description": "Configuration for extreme performance on workloads",
  "name": "Extreme Performance",
  "tags": [
    {
      "internal:bxp:metric:associatedWorkloadCnt": "3"
    }
  ],
  "type": "application/vnd.netapp.bxp.performancepolicy",
  "version": "1.0"
}
====

= Update a system in NetApp Console local deployment
:imagesdir: ../media/

[.api-doc-operation .api-doc-operation-patch]#PATCH# [.api-doc-code-block]#`/v1/organizations/{organizationId}/workingenvironments/{workingEnvironmentId}`#



Updates the system. Include only the fields you want to update in the request.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|organizationId
|string
|path
|True
a|Organization ID

* example: 3fa85f64-5717-4562-b3fc-2c963f66afa6


|workingEnvironmentId
|string
|path
|True
a|System ID

* example: OnPremWorkingEnvironment-3fa85f64-5717-4562-b3fc-2c963f66afa6


|===

== Request Body

                   

[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|password
|string
|False
a|ONTAP cluster password

* example: NetApp123!
* format: password


|username
|string
|False
a|ONTAP cluster username

* example: admin


|===


.Example request
[%collapsible%closed]
====
[source,json,subs=+macros]
{
  "password": "NetApp123!",
  "username": "admin"
}
====

== Response

